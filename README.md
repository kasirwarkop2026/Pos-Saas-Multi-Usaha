# POS SaaS Multi-Usaha — Super Admin

Frontend foundation for the Super Admin platform, based on Blueprint Super Admin v1.0.

## Scope
- Next.js App Router frontend
- Dashboard and 11 blueprint navigation areas
- Clearly labeled illustrative/demo data
- No Supabase integration or backend actions in this initial frontend-only phase

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Vercel
Import this repository into Vercel. Framework preset: Next.js; root directory: `./`; production branch: `main`. No environment variables are required for this UI-only preview.

All displayed business, payment, and analytics values are illustrative and are not production data.
